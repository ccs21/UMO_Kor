# 우타마크로스 한국어판 1.1.16-ko-beta.1

첫 공개 Android 베타입니다. **Release 빌드이며 Development/디버그 빌드가 아닙니다.** 다만 완성판이 아닌 테스트용 사전 릴리스입니다.

## 설치

아래 APK를 설치하고 [한국어 설치 안내](https://github.com/ccs21/UMO_Kor#android-설치-방법)를 따라 원본 UMO 서버로 데이터를 설치하세요. 게임 데이터 아카이브와 PC 패치는 이 릴리스에 포함하지 않습니다. 다운로드 출처는 README의 원본 설치 문서 링크를 이용합니다.

## 변경 사항

- 한국어 텍스트 내장 및 한국어 기본 시작, 앱 이름 우타마크로스.
- 번역 문자열의 줄바꿈 및 텍스트 적용 보완.
- 배포 전용 패키지 `com.ccs21.umokor`, versionCode `10001`, 고정 릴리스 서명.
- Windows 독립 실행 빌드/PC 그래픽 보완 소스를 함께 공개. PC 실행본·게임 데이터·변환 캐시는 미첨부.

## 세이브와 업데이트

원본 일본어판 및 이전 개발용 테스트판과는 별도 앱입니다. **기존 일본어판 세이브 호환·자동 승계는 지원하지 않습니다.** 원본 앱을 삭제하거나 초기화하지 마세요.

이 베타 이후 한국어판은 같은 앱 ID와 서명으로 배포합니다. 새 APK를 삭제 없이 덮어 설치하는 업데이트 방침이며, 세이브와 다운로드 데이터를 유지하도록 관리합니다. 후속 버전에서의 실제 업데이트 검증은 별도로 필요합니다. 업데이트 전에 계정·설정을 백업하세요.

## 알려진 제한 / 검사 범위

- 이미지에 그려진 일본어와 일부 번역 오류가 남아 있습니다. 100% 한글화가 아닙니다.
- Android 릴리스 빌드, APK 서명·식별자·버전·디버그 여부를 검사합니다. 이번 배포 APK의 신규 설치·전곡 플레이·기종별 동작은 실기 재검증 전입니다.
- PC 전체 이미지 캐시 검사는 38,553개 파일, 오류 0으로 완료했지만 실제 화면 전체가 검증된 것은 아닙니다. 일부 그래픽·튜토리얼·입력 문제는 남을 수 있습니다.
- 원본 UMO 서버를 사용합니다. 한국어 서버, 자동 ZIP 설치기, 별도 키 설정 도구, 로그인 보너스 DLC 자동 설치는 미제공입니다.

문제 제보에는 APK 버전, 기종/Android 버전, 재현 순서와 화면을 첨부해 주세요. 개인 세이브와 서명 키는 공개하지 마세요.
