# 우타마크로스 한국어판 1.1.16-ko-beta.5

## 변경 사항

- 우타히메 스테이터스 항목명·랭킹에 한글이 네모로 표시되는 폰트 적용 누락을 수정했습니다. 이름과 대사에 사용하는 시스템 폰트를 재사용합니다.
- 같은 공통 함수를 사용하는 곡 선택 화면의 안내·잔여 시간에도 한국어 폰트 처리를 적용합니다. PC와 Android 공통 수정입니다.
- 수정4까지의 번역을 모두 유지합니다.

## 업데이트

기존 한국어판을 **삭제하지 말고** APK를 덮어 설치하세요.
앱 ID `com.ccs21.umokor`와 기존 릴리스 서명을 유지하며 versionCode는 `10005`입니다.
세이브·다운로드 데이터의 경로와 형식은 변경하지 않습니다. 중요한 프로필은 먼저 백업해 주세요.
Android 실기에서의 업데이트 및 해당 화면 검증은 아직 완료하지 않았습니다.
원본 일본어판 및 별도 개발 테스트 앱의 세이브 자동 이전은 지원하지 않습니다.

## 설치 및 제한

- 설치와 원본 UMO 서버 사용은 [한국어 README](https://github.com/ccs21/UMO_Kor#readme)를 참고하세요.
- 데이터는 [원본 설치 안내](https://umo.xele.org/getting-started/installation/install-android/)의 Game datas 링크를 이용하세요.
- 이미지 속 일본어 등 미번역 부분은 남아 있습니다. 100% 한글화 완성판이 아닙니다.
- 릴리스 자산은 Android APK와 `SHA256SUMS.txt`입니다. 아카이브·PC 패치·세이브·서명 키는 포함하지 않습니다.
