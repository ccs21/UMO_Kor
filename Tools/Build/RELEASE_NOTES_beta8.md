# 우타마크로스 한국어판 1.1.17-ko-beta.8

## 변경 사항

- 원본 UMO 1.1.17 변경 사항을 한국어판에 반영했습니다.
- 화면에서 검수한 한국어 이미지 43개를 Android와 Windows 빌드에 공통으로 내장했습니다.
- 공식 로그인 보너스 DLC를 Android에서는 첫 실행 시 자동 설치하고, Windows에서는 빌드 도우미가 내려받아 변환하도록 했습니다.
- Windows 빌드의 셰이더와 튜토리얼 표시 보완 및 PC 전용 입력 개선을 포함합니다.
- 이미지 작업용 F8/F9 덤프·즉시 교체 기능은 일반 배포 빌드에서 제외했습니다.

## 설치 및 업데이트

- Android 신규 사용자: `UMO_Kor_For_Android_20260910.zip`을 받고 압축 안의 APK와 서버 도우미를 사용하세요.
- Windows: `UMO_Kor_For_windows_20260910.zip`을 풀고 동봉 PDF를 읽은 뒤 빌드 도우미를 실행하세요.
- 기존 한국어 Android판 사용자는 `UMO_Kor-1.1.17-ko-beta.8.apk`만 받아 앱을 삭제하지 않고 덮어 설치하세요. 앱 ID `com.ccs21.umokor`와 기존 서명을 유지하며 versionCode는 `10008`입니다.
- 원본 일본어판 및 개발 테스트판의 세이브 자동 이전은 지원하지 않습니다.

이미지 번역은 아직 일부만 완료됐고 일부 PC 그래픽 문제와 전곡·전 의상·게임패드 검증이 남아 있으므로 이번 릴리스도 베타입니다. 게임 데이터 아카이브, PC 패치, 변환 캐시, 세이브와 서명 키는 배포물에 포함하지 않습니다.

Windows 릴리스 빌드 실행에서 공통 이미지와 여러 실제 번들 이미지의 교체를 확인했습니다. Android APK는 빌드·서명·패키지·버전·ABI 검사를 통과했지만 이번 작업 시 연결된 기기가 없어 beta.7 위 덮어설치 실기 검사는 진행하지 못했습니다.

릴리스 자산은 Windows 신규 사용자용 ZIP, Android 신규 사용자용 ZIP, Android 기존 사용자 업데이트용 APK의 세 파일입니다.
