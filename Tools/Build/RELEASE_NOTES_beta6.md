# 우타마크로스 한국어판 1.1.16-ko-beta.6

## 변경 사항

- 스테이터스 항목 `의상 강화 스테이터스`를 `의상강화`로 줄여 줄바꿈으로 다음 항목과 겹치는 문제를 보완했습니다. PC·Android 공통 번역입니다.
- beta.5의 한글 폰트 수정과 수정4까지의 번역을 유지합니다.
- PC 소스에는 간헐적 종료 크래시 추적용 파일 기록을 추가했습니다. 크래시 해결이 확인된 버전은 아닙니다. Android에서는 해당 기록을 사용하지 않습니다.

## 업데이트

기존 한국어판을 **삭제하지 말고** APK를 덮어 설치하세요.
앱 ID `com.ccs21.umokor`와 기존 서명을 유지하며 versionCode는 `10006`입니다.
세이브·다운로드 데이터의 경로 및 형식은 변경하지 않습니다. 중요한 프로필은 먼저 백업해 주세요.
Android 실기 화면 및 업데이트 검사는 아직 완료하지 않았습니다.
원본 일본어판 및 별도 개발 테스트 앱의 세이브 자동 이전은 지원하지 않습니다.

- 설치 및 원본 서버 이용: [한국어 README](https://github.com/ccs21/UMO_Kor#readme).
- 데이터: [원본 설치 안내](https://umo.xele.org/getting-started/installation/install-android/)의 Game datas 링크.
- 이미지 속 일본어 등 미번역 부분은 남아 있습니다.
- 자산은 APK와 `SHA256SUMS.txt`이며 아카이브·PC 패치·세이브·서명 키는 포함하지 않습니다.
