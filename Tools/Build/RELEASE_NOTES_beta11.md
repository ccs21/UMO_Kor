# 우타마크로스 한국어판 1.1.17-ko-beta.11

## 변경 사항

- Android와 PC의 검수 완료 한국어 이미지를 52개에서 78개로 갱신했습니다.
- 가챠, 의상 선택, 체크 화면 등 새 번역 이미지 26개를 같은 공용 이미지 세트에 추가했습니다.
- PC 빌드 도우미의 마지막 화면을 정리하고, 기존 빌드와 텍스처 캐시를 검사해 변경된 항목만 다시 처리하도록 개선했습니다.
- 작업용 Windows 빌드에도 공식 로그인 보너스 DLC를 설치해 모바일판과 같은 기간 보상 화면을 확인할 수 있도록 했습니다.

## 설치 및 업데이트

- Android 신규 사용자: `UMO_Kor_For_Android_20260927.zip`을 받고 압축 안의 APK와 서버 도우미를 사용하세요.
- Windows: `UMO_Kor_For_windows_20260927.zip`을 풀고 동봉 PDF를 읽은 뒤 빌드 도우미를 실행하세요.
- 기존 한국어 Android판 사용자는 `UMO_Kor-1.1.17-ko-beta.11.apk`만 받아 앱을 삭제하지 말고 덮어 설치하세요. 앱 ID `com.ccs21.umokor`와 기존 서명을 유지하며 versionCode는 `10011`입니다.
- 원본 일본어판 및 개발 테스트판의 세이브 자동 이전은 지원하지 않습니다.

이미지 번역은 아직 일부만 완료됐고 일부 PC 그래픽 문제와 전곡·전 의상·게임패드 검증이 남아 있어 이번 릴리스도 베타입니다.

Android APK는 빌드·서명·패키지·버전·ABI 검사를 통과한 뒤 게시합니다. 이번 beta.11의 실기 덮어 설치 검사는 릴리스 시점에 별도로 완료하지 않았습니다.

릴리스 자산은 Windows 신규 사용자용 ZIP, Android 신규 사용자용 ZIP, Android 기존 사용자 업데이트용 APK의 세 파일입니다.
