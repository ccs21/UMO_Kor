# 우타마크로스 한국어판 1.1.17-ko-beta.10

## 변경 사항

- Android와 PC의 검수 완료 한국어 이미지를 43개에서 52개로 갱신했습니다.
- 홈 메뉴, 옵션, 어빌리티 등 새 번역과 기존 이미지 수정본을 같은 공용 이미지 세트로 교체했습니다.
- PC 저장 데이터가 실행 파일 옆 `UserData`만 사용하도록 정리해, 새 폴더에서 과거 LocalLow 저장 데이터를 다시 불러오는 문제를 수정했습니다.
- PC의 Unity 기본 LocalLow 로그를 끄고 게임 폴더의 `UserData/Log.txt`와 `Log_Prev.txt`를 사용하도록 변경했습니다.
- 이미지 작업용 F8 덤프의 0바이트 중단, 반복 오류 및 이미 번역된 오버라이드의 중복 덤프를 수정했습니다. F8/F9 작업 기능은 일반 배포 빌드에 포함되지 않습니다.

## 설치 및 업데이트

- Android 신규 사용자: `UMO_Kor_For_Android_20260922.zip`을 받고 압축 안의 APK와 서버 도우미를 사용하세요.
- Windows: `UMO_Kor_For_windows_20260922.zip`을 풀고 동봉 PDF를 읽은 뒤 빌드 도우미를 실행하세요.
- 기존 한국어 Android판 사용자는 `UMO_Kor-1.1.17-ko-beta.10.apk`만 받아 앱을 삭제하지 말고 덮어 설치하세요. 앱 ID `com.ccs21.umokor`와 기존 서명을 유지하며 versionCode는 `10010`입니다.
- 원본 일본어판 및 개발 테스트판의 세이브 자동 이전은 지원하지 않습니다.

이미지 번역은 아직 일부만 완료됐고 일부 PC 그래픽 문제와 전곡·전 의상·게임패드 검증이 남아 있어 이번 릴리스도 베타입니다.

Android APK는 빌드·서명·패키지·버전·ABI 검사를 통과했습니다. 이번 beta.10의 실기 덮어 설치 검사는 릴리스 시점에 별도로 완료하지 않았습니다.

릴리스 자산은 Windows 신규 사용자용 ZIP, Android 신규 사용자용 ZIP, Android 기존 사용자 업데이트용 APK의 세 파일입니다.
