# 우타마크로스 한국어판 1.1.16-ko-beta.2

Android 한국어판 두 번째 베타입니다. 서명된 Release APK이며 개발/디버그 빌드가 아닙니다.

## 변경 사항

- `번역_수정2.xlsx`의 수정 번역 중 런타임 텍스트 519개를 공용 한국어 언어팩에 반영했습니다.
- 선물 화면의 획득/수령 시각과 일부 기존 일본어 보상 설명을 한국어로 표시하도록 보완했습니다.
- 이미지 내 문구 수정 3개는 번역 원본에 기록했습니다. 오프닝 등 이미지 자체의 한국어 교체는 아직 적용하지 않았습니다.
- 저장소에는 PC 키/게임패드 설정 도구, 판정 보조·저부하 설정, 이동 롱노트 및 이펙트 보정, 테스트 복사본 전용 재화·소재 충전 기능도 포함됩니다. 이 PC 전용 기능은 Android APK의 입력·판정·자원을 변경하지 않습니다.

## 기존 한국어판 업데이트

한국어판 beta.1을 **삭제하지 말고** 새 APK를 덮어 설치하세요.
앱 ID `com.ccs21.umokor`와 기존 릴리스 서명을 유지하고 versionCode를 `10001`에서 `10002`로 올렸습니다.
세이브·데이터 경로를 바꾸거나 초기화하는 업데이트가 아닙니다. 중요한 프로필은 업데이트 전에 백업해 주세요.
서명·앱 ID·버전·비디버그 빌드 검사는 배포 전에 수행하며, Android 실기에서의 덮어 설치/플레이 검증은 아직 미완료입니다.
원본 일본어판 및 별도 개발 테스트 앱의 세이브 자동 이전은 지원하지 않습니다.

## 설치 및 알려진 제한

- 신규 설치 및 원본 UMO 서버 사용 방법은 [한국어 README](https://github.com/ccs21/UMO_Kor#readme)를 참고하세요. 서버는 원본 서버를 그대로 사용합니다.
- 아카이브/PC 패치는 [원본 설치 안내](https://umo.xele.org/getting-started/installation/install-android/)의 Game datas 링크에서 받으세요. 이번 릴리스에 게임 데이터 아카이브·PC 패치·변환 캐시·개인 세이브는 포함하지 않습니다.
- 일본어가 이미지에 포함된 메뉴·버튼·오프닝 등은 아직 남아 있습니다. 완성판이 아닌 검수용 베타입니다.
- 첨부 `SHA256SUMS.txt`는 APK 파일 해시입니다. 서명 키 및 암호는 공개하지 않습니다.
