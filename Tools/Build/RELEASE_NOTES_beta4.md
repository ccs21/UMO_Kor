# 우타마크로스 한국어판 1.1.16-ko-beta.4

## 변경 사항

- beta.3의 번역에 `번역_수정4.xlsx`의 대사 수정 1개를 추가했습니다.
- `셰릴시ェ리`를 `셰리셰리`로 수정했습니다. 기존 수정1~3의 번역도 포함합니다.
- 저장소에는 PC 원본 프로필 자원 충전 도구의 백업·확인 절차와 테스트가 포함됩니다. 이 도구는 PC 전용이며 Android APK의 자원이나 세이브를 변경하지 않습니다.

## 기존 한국어판 업데이트

기존 한국어판을 **삭제하지 말고** APK를 덮어 설치하세요.
앱 ID `com.ccs21.umokor`와 기존 릴리스 서명을 유지하며 versionCode는 `10004`입니다.
세이브 및 다운로드 데이터의 경로·형식을 변경하거나 초기화하지 않습니다. 중요한 프로필은 업데이트 전에 백업해 주세요.
Android 실기에서의 업데이트·플레이 검사는 아직 완료하지 않았습니다.
원본 일본어판 및 별도 개발 테스트 앱의 세이브 자동 이전은 지원하지 않습니다.

## 설치 및 알려진 제한

- 신규 설치 및 원본 UMO 서버 사용은 [한국어 README](https://github.com/ccs21/UMO_Kor#readme)를 참고하세요.
- 아카이브·PC 패치는 [원본 설치 안내](https://umo.xele.org/getting-started/installation/install-android/)의 Game datas 링크를 이용하세요.
- 이미지 속 일본어, 코드의 일부 이벤트 이름과 곡 제목 원문 병기는 아직 남아 있습니다. 100% 한글화 완성판이 아닙니다.
- 이번 릴리스의 실행 파일 자산은 Android APK입니다. 게임 데이터 아카이브·PC 패치·캐시·세이브·개인 서명 키는 포함하지 않습니다.
- `SHA256SUMS.txt`로 APK의 파일 해시를 확인할 수 있습니다.
