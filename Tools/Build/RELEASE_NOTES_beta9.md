# 우타마크로스 한국어판 1.1.17-ko-beta.9

## 변경 사항

- beta.8에서 Unity 로고 후 검은 화면에 멈추던 문제를 수정했습니다.
- `1.1.17-ko-beta.8`과 같은 한국어판 버전 문자열을 DLC 호환성 검사가 정수로 변환하다 예외를 발생시키던 것이 원인이었습니다.
- 버전 비교가 숫자 버전 `1.1.17`을 안전하게 읽고 `-ko-beta.*` 접미사를 허용하도록 보완했으며, 회귀 검사를 추가했습니다.
- beta.8의 한국어 이미지 43개, 공식 로그인 보너스 DLC, Windows 빌드 도우미 및 PC 개선 사항을 모두 포함합니다.
- 이미지 작업용 F8/F9 덤프·즉시 교체 기능은 일반 배포 빌드에서 제외됩니다.

## 설치 및 업데이트

- Android 신규 사용자: `UMO_Kor_For_Android_20260910.zip`을 받고 압축 안의 APK와 서버 도우미를 사용하세요.
- Windows: `UMO_Kor_For_windows_20260910.zip`을 풀고 동봉 PDF를 읽은 뒤 빌드 도우미를 실행하세요.
- 기존 한국어 Android판 사용자는 `UMO_Kor-1.1.17-ko-beta.9.apk`만 받아 앱을 삭제하지 말고 덮어 설치하세요. 앱 ID `com.ccs21.umokor`와 기존 서명을 유지하며 versionCode는 `10009`입니다.
- beta.8은 실행 불가 문제가 있으므로 beta.9로 업데이트하세요.
- 원본 일본어판 및 개발 테스트판의 세이브 자동 이전은 지원하지 않습니다.

이미지 번역은 아직 일부만 완료됐고 일부 PC 그래픽 문제와 전곡·전 의상·게임패드 검증이 남아 있어 이번 릴리스도 베타입니다.

Android APK는 빌드·서명·패키지·버전·ABI 검사를 통과했습니다. Galaxy S23 Ultra에서 beta.8 위로 삭제 없이 덮어 설치해 데이터 다운로드 화면 진입과 기존 데이터·세이브 로드를 확인했습니다.

릴리스 자산은 Windows 신규 사용자용 ZIP, Android 신규 사용자용 ZIP, Android 기존 사용자 업데이트용 APK의 세 파일입니다.
