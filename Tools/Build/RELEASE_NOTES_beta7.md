# 우타마크로스 한국어판 1.1.16-ko-beta.7

## 변경 사항

- Android 추가 데이터 설치용 한국어 PC 서버 도우미를 추가했습니다.
- 원본 데이터 아카이브와 PC 패치 ZIP을 지정 폴더에 넣으면 압축 해제, 파일 배치, 검증과 서버 시작을 자동으로 처리합니다.
- Android 자동 탐색이 실패할 때 입력할 PC의 로컬 IP를 프로그램에 표시하고 복사할 수 있습니다.
- PC 빌드 도우미와 별도 PDF 사용 설명서를 Windows용 합본 ZIP으로 제공합니다.
- 수정4까지의 번역과 beta.6의 Android 한글 폰트·화면 배치 수정을 유지합니다.

## 설치 및 업데이트

- Android: `UMO_Kor_For_Android_20260907.zip`을 받고 압축 안의 APK와 서버 도우미를 사용하세요.
- Windows: `UMO_Kor_For_windows_20260907.zip`을 풀고 동봉 PDF를 읽은 뒤 빌드 도우미를 실행하세요.
- 기존 한국어 Android판 업데이트 사용자만 `UMO_Kor-1.1.16-ko-beta.7.apk` 단독 파일을 받으면 됩니다. 앱을 삭제하지 말고 APK를 덮어 설치하세요. 앱 ID `com.ccs21.umokor`와 기존 서명을 유지하며 versionCode는 `10007`입니다.
- 원본 일본어판 및 개발 테스트판의 세이브 자동 이전은 지원하지 않습니다.

이미지에 그려진 일본어와 일부 PC 그래픽 문제는 아직 남아 있으므로 이번 릴리스도 베타입니다. 게임 데이터 아카이브, PC 패치, 변환 캐시, 세이브와 서명 키는 배포물에 포함하지 않습니다.

릴리스 자산은 Windows 신규 사용자용 ZIP, Android 신규 사용자용 ZIP, Android 기존 사용자 업데이트용 APK의 세 파일입니다.
