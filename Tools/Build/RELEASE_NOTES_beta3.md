# 우타마크로스 한국어판 1.1.16-ko-beta.3

수정 번역을 반영한 Android 베타 업데이트입니다.

## 변경 사항

- `번역_수정3.xlsx`에서 변경된 런타임 텍스트 27개를 Android·PC 공용 한국어 언어팩에 반영했습니다.
- 마크로스 Δ 미션 설명, 셰릴 관련 대사, 악곡명·스토리 제목, 에피소드 설명 등의 수정입니다. 영어 `Another ver.` 표기는 유지했습니다.
- 빈 번역 칸은 기존 값을 유지하며, 변경 항목의 서식 인자 검사를 통과했습니다.
- 이번 변경은 제출된 번역 파일의 반영입니다. 코드에 직접 적힌 이벤트 이름, 이미지 속 일본어와 곡 제목 원문 병기 설정은 변경하지 않았습니다.
- 제출본에도 `셰릴시ェ리`처럼 일본 문자가 일부 남은 표현이 있어 후속 검수가 필요합니다. 번역 파일의 문구를 임의로 다시 번역하지 않았습니다.

## 업데이트 방법

기존 한국어판 beta.1/beta.2를 **삭제하지 말고** 새 APK를 덮어 설치하세요.
앱 ID `com.ccs21.umokor`와 기존 릴리스 서명은 동일하며 versionCode는 `10003`입니다.
세이브·다운로드 데이터 경로와 형식은 변경하지 않습니다. 중요한 프로필은 업데이트 전에 백업해 주세요.
Android 실기에서의 덮어 설치 및 플레이 검사는 아직 완료하지 않았습니다.
원본 일본어판 및 별도 개발 테스트 앱의 세이브 자동 이전은 지원하지 않습니다.

## 설치 및 제한

- 설치와 원본 UMO 서버 이용 방법은 [한국어 README](https://github.com/ccs21/UMO_Kor#readme)를 참고하세요.
- 데이터 아카이브와 PC 패치는 [원본 설치 안내](https://umo.xele.org/getting-started/installation/install-android/)의 Game datas 링크를 사용합니다.
- 게임 데이터 아카이브·PC 패치·변환 캐시·개인 세이브·개인 서명 키는 배포 자산 및 Git에 포함하지 않습니다.
- PC 소스에도 같은 번역이 적용됩니다. 이번 GitHub 릴리스의 실행 파일 자산은 Android APK입니다.
- `SHA256SUMS.txt`로 APK 파일 해시를 확인할 수 있습니다.
