# PC 종료 크래시 점검 (2026-09-04)

## 확인된 내용

- 기존 PC 빌드 종료 시 UnityPlayer.dll 접근 위반 `0xc0000005` 기록이 있습니다.
- 읽으려던 주소는 `0x50`이며, 호출 기록 하단에는 Mono의 `mono_threads_set_shutting_down`이 있습니다.
- 엔진/관리 코드 프레임 일부에 심볼이 없어 정확한 원인 함수는 확정하지 못했습니다. 메모리 부족이나 세이브 손상으로 단정할 근거는 없습니다.
- 이 문제는 beta.5의 한글 폰트 수정과 별개이며 이번 수정으로 해결되었다고 보장하지 않습니다.

## 추가 확인 대상

- 종료 시 관리 객체 정리 및 Unity API 호출 순서.
- `CriMana.Player` finalizer는 Dispose 경로에서 Unity 객체 접근을 할 수 있습니다. 실제 크래시의 해당 프레임인지 확인이 필요합니다.
- VLC 관리자와 재생 객체의 종료/해제 순서도 점검 대상이지만, DLL이 로드되어 있다는 사실만으로 VLC를 원인으로 판단할 수 없습니다.
- 별도 검수 프로필로 메인 화면 및 영상/악곡 재생 후 정상 종료를 비교하고, 심볼이 있는 스택으로 범위를 좁혀야 합니다.

원본 세이브 및 크래시 덤프는 저장소에 포함하지 않습니다.
