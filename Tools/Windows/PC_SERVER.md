# 우타마크로스 PC 서버

Android판의 약 14GB 추가 데이터를 같은 공유기 안의 PC에서 전송하는 한국어 서버 도우미입니다. Unity 설치, 경로 입력, 명령어 실행이 필요 없습니다.

## 사용 방법

1. Releases의 `UMO_Kor_For_Android_20260910.zip`을 쓰기 가능한 새 폴더에 풀고 `UMO_PC_Server.exe`를 실행합니다.
2. `ZIP 파일 넣을 폴더 열기`를 누릅니다.
3. 열린 `Archives` 폴더에 다음 두 파일을 **압축을 풀지 않고 ZIP 그대로** 넣습니다.
   - `UtaMacrossDataArchive.zip`
   - `UtaMacrossDataArchivePCPatch.zip`
4. `새로고침`을 누른 뒤 `자동 설치 및 서버 시작`을 누릅니다.
5. 완료되어 초록색으로 **서버 실행 중**이 표시되면 Android 기기에서 데이터 설치를 시작합니다.

자동 탐색에 실패하면 게임의 주소 입력 화면에 서버 프로그램이 크게 표시하는 숫자(예: `192.168.0.15`)만 입력합니다. `http://`, `:8000`, `localhost`는 붙이지 않습니다.

처음 실행할 때 Windows 보안 경고가 나타나면 **사설 네트워크**만 체크하고 `액세스 허용`을 누릅니다. PC와 휴대폰은 같은 Wi-Fi/공유기에 연결해야 합니다. 공용 Wi-Fi에서는 사용하지 말고 공유기의 포트 포워딩도 설정하지 마세요.

전송이 끝날 때까지 프로그램을 종료하거나 PC를 절전 상태로 만들지 마세요. 설치된 데이터는 프로그램 옆 `ServerData`에 보존되므로 다음 실행부터 ZIP 압축 해제 없이 서버가 자동으로 시작됩니다. 설치 도중 종료된 경우 같은 버튼을 다시 누르면 완료된 파일은 건너뛰고 이어서 설치합니다.

## 문제 해결

- IP가 보이지 않음: PC의 Wi-Fi 또는 유선 LAN 연결을 확인하고 VPN을 잠시 끈 뒤 `새로고침`을 누릅니다.
- 자동 탐색 실패: 화면의 `Android에 입력할 IP`를 복사하여 게임에 직접 입력합니다.
- 8000/8001 포트 사용 중: 다른 UMO 서버나 같은 포트를 쓰는 프로그램을 종료합니다.
- 연결 실패: Windows 방화벽에서 `UMO_PC_Server.exe`의 사설 네트워크 통신을 허용했는지 확인합니다.
- ZIP 오류/용량 부족: 파일 이름과 다운로드 완료 여부를 확인하고, 서버 폴더가 있는 드라이브에 20GB 이상 여유 공간을 확보합니다.

게임 데이터와 PC 패치는 이 저장소나 서버 프로그램에 포함되지 않습니다. [원본 UMO Android 설치 안내](https://umo.xele.org/getting-started/installation/install-android/)의 Game datas 링크를 이용하세요.
